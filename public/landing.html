Screencast Recorder

Records your work across machines as separate, time-aligned tracks, so a long session can be cut into a short video without hunting through hours of footage.

Open the console

You will be asked to sign in.

How it works

  1. Pick what to record. The console lists what each machine actually has — displays, microphones, cameras — reported by the agent running on it, not guessed.
  2. Press Start once. Every machine synchronises its clock first, then all of them begin at the same instant, so the tracks line up afterwards.
  3. Work normally. Each source records to its own segmented file. If the controller goes down, capture keeps running locally.
  4. Stop, then decide. Nothing leaves the machine until you choose Save. Discard throws the session away.
  5. Saved sessions are verified. A session counts as stored only after every file has been read back from storage.

What it does not record

The activity stream that makes later editing possible captures counts — clicks, keypresses, pointer position, the focused window — and never the characters you type or your clipboard. There is no setting that turns that on. Anything credential-shaped in a window title is redacted before it is written.
